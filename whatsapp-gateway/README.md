# WhatsApp Gateway

Production-ready WhatsApp Gateway built using Node.js, TypeScript, Express and Baileys.

This service is responsible only for WhatsApp communication.

## Features

- Connect WhatsApp
- QR Authentication
- Session Management
- Send Messages
- Receive Messages
- Disconnect
- Unlink

## Out of Scope

- AI
- CRM
- Billing
- Mobile App
- Business Logic
